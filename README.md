# Dead Mall Arena

A 3D first-person shooter set in an abandoned 90s shopping mall overrun by aliens. It runs in a single HTML file, and every texture, sound and song is generated in your browser.

## New: LAN Edition

**[Dead Mall Arena LAN Edition](lan-edition/)** is a full remake of the same mall with new graphics and local-network multiplayer: sun shadows through the skylight, reflections, glowing neon, and everyone on your Wi-Fi sharing the same aliens and power-ups. It comes in an [AMD 395 version](lan-edition/downloads/Dead-Mall-Arena-AMD395.zip) and a [Raspberry Pi 500 version](lan-edition/downloads/Dead-Mall-Arena-Pi500.zip) that can play together.

## What's in it

- Single-player against AI bots, or multiplayer with friends using a party code, including a mode that needs no server at all
- Six weapons: sawed-off shotgun, pistol, SMG, rifle, sniper, and an RPG from the fortune teller. Take a weapon from anyone you defeat
- Pickups: med-kits, weapon crates, speed boosts, shields, cloaking devices, and vending machines
- A big two-floor mall to explore: 40 storefronts, seasonal displays, an arcade, a pizza place with a working conveyor kitchen, a movie theater, a go-kart museum, a dive bar with pool, darts and a jukebox, a fortune teller, and a CompUSA with an unhinged ex-employee
- A low-power mode for weaker hardware like the Raspberry Pi

## Controls

| Key | Action |
|---|---|
| WASD / Mouse | Move and look |
| Hold click | Fire |
| R | Reload |
| E | Interact |
| G | Throw a grenade |
| Y / N | Answer yes or no |
| M | Toggle music |
| T | Text chat |
| Esc | Release the mouse |

## Run it

Download `arena-final b11.html` and open it in your web browser. On a Raspberry Pi 400, use `arena-RPI400-version.html` instead.

The full guide is in `Dead Mall Arena — Player's Manual.pdf`.
